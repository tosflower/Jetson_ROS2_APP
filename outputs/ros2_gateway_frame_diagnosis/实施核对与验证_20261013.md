# 网关专利方案实施核对与验证

本说明承接本目录 20261013112000 版交底书，用于记录本次“可验证的选择事件诊断机制”代码落地情况。原交底书保留为拟议方案，不将本次局部实现扩写成全部方案已经落地。

## 已完成的代码链路

1. `gateway/images.py` 为实际共享订阅分配世代标识，同一订阅的客户端共用世代，重新创建订阅产生新世代。记录回调数、成功生成帧数及转换失败数。
2. `gateway/diagnostics.py` 按客户端会话建立有界账本，在真实发送选帧处记录帧号、上次所选帧号和网关单调时间。首次加入前的帧不计入跳号。窗口最多 128 帧。
3. `gateway/gateway.py` 在二进制写出返回后登记本地写出事件，按“世代、会话、帧号”接纳诊断回执，并提供认证接口 `GET /api/images/diagnostics`。断线移除流账本并释放订阅引用。
4. `providers/gateway-provider.tsx` 回传接收及加载证据，并且只在待解码槽位确实被新帧覆盖时回传主动替换事件。没有原生加载回调的帧不能自动认定为主动替换。

## 验证与证据边界

诊断单元测试覆盖：首次加入基线、快慢客户端选帧差异、写出及回执观察超时、迟到回执修正、跨世代和跨会话回执拒绝、畸形帧号拒绝、主动替换证据要求、矛盾回执和容量淘汰。

网关流程测试通过真实 `mobile_stream` 协程和模拟 ROS 执行器验证：两个客户端复用订阅、各自会话隔离、元数据携带身份、二进制写出登记、加载回执进入对应账本，以及双端断开后订阅与诊断记录清空。

执行命令：

```bash
python3 -m unittest discover -s gateway -p 'test_diagnostics.py' -v
python3 -m unittest discover -s gateway -p 'test_streaming.py' -v
python3 -m unittest discover -s gateway -p 'test_gateway_api.py' -v
npx tsc --noEmit
```

本轮验证使用模拟 ROS 和内存 WebSocket，不代表完成 Jetson、Android 原生图片加载、真实无线网络或 DDS 测试。观察超时仅表达后继证据缺失，不能直接确定网络丢包；网关帧号也不能用于推断 ROS 发布端或 DDS 的消息损失。尚无实机性能收益数据。

验证结果：5 项诊断测试、2 项计时测试、8 项网关接口测试全部通过；TypeScript `tsc --noEmit` 通过。接口测试在沙箱内曾因受限环境出现异步等待超时，经授权在沙箱外重跑通过（8 项合计约 0.64 秒）。环境提示缺少 zeroconf，故本轮未验证 mDNS 公告；另有既存 Pydantic 配置弃用提示，不影响本轮测试结果。
